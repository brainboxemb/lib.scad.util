# lib.scad.util user manual

## Use the library

Normal OpenSCAD consumers import the inspection helper directly:

```scad
use <openscad/inspection.scad>

util_section_inspect(
    axis = "Z",
    position = 0,
    depth = 0.1,
    direction = "Positive"
)
    my_model();
```

`axis="None"` deliberately passes children through unchanged.

## Managed inspection controls

The library also owns a canonical Customizer-variable block for interactive
section inspection. The synchronization scripts under `consumer/` insert or
refresh that managed block idempotently in consumer models.

## API boundary

`lib.scad.util` does not provide the shared modeling language. Transforms,
coordinate frames, tagged CSG, cutters and overlap semantics belong to
`lib.scad.forge`.

For the exact inspection geometry and semantics, see the
[source-adjacent inspection design](../openscad/inspection/design/design.md) and
the owning source `openscad/inspection.scad`.

## Versions

Consumers should pin an explicit released util version and update deliberately.
Older releases may still contain historical `xf_*` / `fg_*` surfaces; those
are not part of the current inspection-focused library boundary.
